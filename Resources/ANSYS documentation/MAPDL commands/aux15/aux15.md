# /AUX15

PyMAPDL: `mapdl.aux15(**kwargs)`

Enters the IGES file transfer processor.

## Notes

Enters the IGES file-transfer processor (auxiliary processor AUX15), used to read an IGES data file into the Mechanical APDL program.

This command is valid only at the Begin Level.
