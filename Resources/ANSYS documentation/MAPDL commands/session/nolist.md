# /NOLIST

PyMAPDL: `mapdl.nolist(**kwargs)`

Suppresses the data input listing.

## Notes

Printout is suppressed until a [[golist|/GOLIST]] command is read or the end of the listing is encountered.

This command is valid in any processor, but only within a batch run ( `/BATCH` ).
