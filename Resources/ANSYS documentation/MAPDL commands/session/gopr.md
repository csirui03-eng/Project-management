# /GOPR

PyMAPDL: `mapdl.gopr(**kwargs)`

Reactivates suppressed printout.

## Notes

Reactivates printout suppressed with the [[nopr|/NOPR]] command. The [[slashgo|/GO]] command has the same function except that it does not produce a command response from the program.

This command is valid in any processor.
