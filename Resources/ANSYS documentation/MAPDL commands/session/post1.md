# /POST1

PyMAPDL: `mapdl.post1(**kwargs)`

Enters the database results postprocessor.

## Notes

Enters the general database results postprocessor (POST1). All load symbols ( [[pbc|/PBC]], [[psf|/PSF]], or [[pbf|/PBF]] ) are automatically turned off with this command.

This command is valid only at the Begin Level.
