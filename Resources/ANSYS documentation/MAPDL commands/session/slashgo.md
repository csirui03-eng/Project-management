# /GO

PyMAPDL: `mapdl.slashgo(**kwargs)`

Reactivates suppressed printout.

## Notes

Reactivates printout suppressed with the [[nopr|/NOPR]] command without producing any output. The [[gopr|/GOPR]] command has the same function except that it also produces a command response from the program.

This command is valid in any processor.
