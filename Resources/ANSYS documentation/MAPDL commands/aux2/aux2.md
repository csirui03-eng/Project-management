# /AUX2

PyMAPDL: `mapdl.aux2(**kwargs)`

Enters the binary file dumping processor.

## Notes

Enters the binary file-dumping processor (auxiliary processor AUX2), used for dumping the contents of certain Mechanical APDL binary files for visual examination.

This command is valid only at the Begin Level.
