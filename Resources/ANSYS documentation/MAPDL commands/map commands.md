# Mapping processor commands

The /MAP processor allows you to map data from an external file onto the existing geometry.

8 commands. Back to [[MAPDL commands]].

| Command | Method | Summary |
|---|---|---|
| [[ftype\|FTYPE]] | `ftype` | Specifies the file type and pressure type for the subsequent import of source points and pressures. |
| [[map\|MAP]] | `map` | Maps pressures from source points to target surface elements. |
| [[slashmap\|/MAP]] | `slashmap` | Enters the mapping processor. |
| [[plgeom\|PLGEOM]] | `plgeom` | Plots target and source geometries. |
| [[plmap\|PLMAP]] | `plmap` | Plots target and source pressures. |
| [[read\|READ]] | `read` | Reads coordinate and pressure data from a file. |
| [[target\|TARGET]] | `target` | Specifies the target nodes for mapping pressures onto surface effect elements. |
| [[writemap\|WRITEMAP]] | `writemap` | Writes interpolated pressure data to a file. |
