# SSUM

PyMAPDL: `mapdl.ssum(**kwargs)`

Calculates and prints the sum of element table items.

## Notes

Calculates and prints the tabular sum of each existing labeled result item ( [[etable|ETABLE]] ) for the selected elements. If absolute values are requested ( [[sabs|SABS]],1), absolute values are used.
