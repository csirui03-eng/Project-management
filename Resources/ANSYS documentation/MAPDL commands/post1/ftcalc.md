# FTCALC

PyMAPDL: `mapdl.ftcalc(nloc='', node='', **kwargs)`

Performs fatigue calculations for a given node location.

## Parameters

**nloc**: Location number of stress conditions to be used for fatigue calculation.

**node**: Node number (used only for convenience if `NLOC` is not input).
