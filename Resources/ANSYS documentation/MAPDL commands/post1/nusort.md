# NUSORT

PyMAPDL: `mapdl.nusort(**kwargs)`

Restores original order for nodal data.

## Notes

This command restores the nodal data to its original order (sorted in ascending node number sequence) after an [[nsort|NSORT]] command. Changing the selected nodal set ( [[nsel|NSEL]] ) also restores the original nodal order.
