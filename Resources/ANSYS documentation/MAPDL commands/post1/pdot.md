# PDOT

PyMAPDL: `mapdl.pdot(labr='', labx1='', laby1='', labz1='', labx2='', laby2='', labz2='', **kwargs)`

Calculates the dot product of two path vectors along the current path.

## Parameters

**labr**: Label assigned to dot product result.

**labx1**: X-component of first vector label (labeled path item).

**laby1**: Y-component of first vector label (labeled path item).

**labz1**: Z-component of first vector label (labeled path item).

**labx2**: X-component of second vector label (labeled path item).

**laby2**: Y-component of second vector label (labeled path item).

**labz2**: Z-component of second vector label (labeled path item).
