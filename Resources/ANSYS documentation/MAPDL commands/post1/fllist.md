# FLLIST

PyMAPDL: `mapdl.fllist(nloc1='', nloc2='', ninc='', **kwargs)`

Lists the fatigue location parameters.

## Parameters

**nloc1**, **nloc2**, **ninc**: List location parameters from `NLOC1` (defaults to 1) to `NLOC2` (defaults to `NLOC1` ) in steps of `NINC` (defaults to 1). If `NLOC1` = ALL, `NLOC2` and `NINC` are ignored and all locations are listed.
