# SUDEL

PyMAPDL: `mapdl.sudel(surfname='', **kwargs)`

Delete geometry information as well as any mapped results for specified surface.

## Parameters

**surfname**

Eight character surface name.

`SurfName` = ALL will delete all surface geometry and result information.
