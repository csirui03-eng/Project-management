# /ICLWID

PyMAPDL: `mapdl.iclwid(factor='', **kwargs)`

Scales the line width of circuit builder icons.

## Parameters

**factor**: Multiplication factor applied to the default line width (defaults to 1). The minimum is 1 and the maximum is 6.
