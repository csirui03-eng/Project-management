# *VSTAT

PyMAPDL: `mapdl.vstat(**kwargs)`

Lists the current specifications for the array parameters.

## Notes

Lists the current specifications for the [[vabs|*VABS]], [[vcol|*VCOL]], [[vcum|*VCUM]], [[vfact|*VFACT]], [[vlen|*VLEN]], and [[vmask|*VMASK]] commands.

This command is valid in any processor.
