# *RENAME

PyMAPDL: `mapdl.starrename(oldname='', newname='', **kwargs)`

Renames an existing vector or matrix.

## Parameters

**oldname**: Name of the existing vector or matrix to be renamed.

**newname**: New name for the vector or matrix.

## Notes

The **\*RENAME** command is used to rename [APDL Math](https://ansyshelp.ansys.com/Views/Secured/corp/v232/en/ans_apdl/apdlmathex.html) objects.
