# AUX3 commands

The auxiliary processor /AUX3 allows you to operate on results files by deleting sets or by changing values.

7 commands. Back to [[MAPDL commands]].

| Command | Method | Summary |
|---|---|---|
| [[aux3\|/AUX3]] | `aux3` | Enters the results file editing processor. |
| [[compress\|COMPRESS]] | `compress` | Deletes all specified sets. |
| [[delete\|DELETE]] | `delete` | Specifies sets in the results file to be deleted before postprocessing. |
| [[fileaux3\|FILEAUX3]] | `fileaux3` | Specifies the results file to be edited. |
| [[list\|LIST]] | `list` | Lists out the sets in the results file. |
| [[modify\|MODIFY]] | `modify` | Changes the listed values of the data in a set. |
| [[undelete\|UNDELETE]] | `undelete` | Removes results sets from the group of sets selected for editing. |
