# NSLK

PyMAPDL: `mapdl.nslk(type_='', **kwargs)`

Selects those nodes associated with the selected keypoints.

## Parameters

**type_**

Label identifying the type of node select:

- `S` - Select a new set (default).
- `R` - Reselect a set from the current set.
- `A` - Additionally select a set and extend the current set.
- `U` - Unselect a set from the current set.

## Notes

Valid only if the nodes were generated by a keypoint meshing operation ( [[kmesh|KMESH]], [[lmesh|LMESH]], [[amesh|AMESH]], [[vmesh|VMESH]] ) on a solid model that contains the selected keypoints.

This command is valid in any processor.
