# AMBEAM

PyMAPDL: `mapdl.ambeam(numbeams='', **kwargs)`

For multiple-beam printers, specifies the number of beams in an [additive manufacturing](https://ansyshelp.ansys.com/Views/Secured/corp/v232/en/add_ag/add_ag_cal.html) analysis.

## Parameters

**numbeams**: Number of beams used in the build process. Default = 1.

## Notes

This command is also valid in PREP7.

For more information, including a list of the elements and commands used in an additive manufacturing analysis, see [AM Process Simulation in Workbench Additive](https://ansyshelp.ansys.com/Views/Secured/corp/v232/en/add_ag/add_ag_AM_in_WB.html#add_ag_load_addon)
