# DJLIST

PyMAPDL: `mapdl.djlist(elem='', **kwargs)`

Lists boundary conditions applied to joint elements.

## Parameters

**elem**: Element number or ALL (or blank). Lists joint element boundary conditions on the specified element(s).

## Notes

This command is valid for `MPC184` joint elements. See [[dj|DJ]] for information on specifying boundary conditions on joint elements.
