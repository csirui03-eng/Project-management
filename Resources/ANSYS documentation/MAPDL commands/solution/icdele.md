# ICDELE

PyMAPDL: `mapdl.icdele(**kwargs)`

Deletes initial conditions at nodes.

## Notes

Deletes all initial conditions previously specified with the [[ic|IC]] or [[icrotate|ICROTATE]] command at all nodes.

This command is also valid in PREP7.
