# SBCLIST

PyMAPDL: `mapdl.sbclist(**kwargs)`

Lists solid model boundary conditions.

## Notes

Lists all solid model boundary conditions for the selected solid model entities. See also [[dklist|DKLIST]], [[dllist|DLLIST]], [[dalist|DALIST]], [[fklist|FKLIST]], [[sfllist|SFLLIST]], [[sfalist|SFALIST]], [[bfllist|BFLLIST]], [[bfalist|BFALIST]], [[bfvlist|BFVLIST]], and [[bfklist|BFKLIST]] to list items separately.

This command is valid in any processor.
