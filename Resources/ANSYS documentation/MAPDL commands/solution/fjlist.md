# FJLIST

PyMAPDL: `mapdl.fjlist(elem='', **kwargs)`

Lists forces and moments applied on joint elements.

## Parameters

**elem**: Element number or ALL (or blank). Lists joint element forces and moments on the specified element(s).

## Notes

Notes Valid for `MPC184` joint elements. See [[fj|FJ]] for information on specifying forces and moments.
