# VARNAM

PyMAPDL: `mapdl.varnam(ir='', name='', **kwargs)`

Names (or renames) a variable.

## Parameters

**ir**: Reference number of the variable (2 to NV ( [[numvar|NUMVAR]] )).

**name**: Thirty-two character name for identifying variable on printouts and displays. Embedded blanks are compressed for output.
