# NPRINT

PyMAPDL: `mapdl.nprint(n='', **kwargs)`

Defines which time points stored are to be listed.

## Parameters

**n**: List data associated with every `N` time (or frequency) point(s), beginning with the first point stored (defaults to 1).

## Notes

Defines which time (or frequency) points within the range stored are to be listed.
