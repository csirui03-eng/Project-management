# LIST

PyMAPDL: `mapdl.list(level='', **kwargs)`

Lists out the sets in the results file.

## Parameters

**level**: The description of the argument is missing in the Python function. Please, refer to the [command documentation](https://ansyshelp.ansys.com/Views/Secured/corp/v232/en//ans_cmd/Hlp_C_LIST.html) for further information.

## Notes

This command lists the results set number, the load step, substep, and time step for each set. It also shows all sets marked for deletion.

The **LIST** command is valid only in the results file editing processor (auxiliary processor AUX3).
