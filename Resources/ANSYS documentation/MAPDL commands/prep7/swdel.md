# SWDEL

PyMAPDL: `mapdl.swdel(ecomp='', **kwargs)`

Deletes spot weld sets.

## Parameters

**ecomp**: Name of an existing spot weld set that was previously defined using [[swgen|SWGEN]]. If `Ecomp` = ALL (default) all spot welds are deleted.

## Notes

This command deletes spot weld sets previously defined by the [[swgen|SWGEN]] command.
