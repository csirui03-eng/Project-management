# PPRES

PyMAPDL: `mapdl.ppres(press='', **kwargs)`

Defines the internal pressure for a piping run.

## Parameters

**press**: Pipe internal pressure.

## Notes

Defines the pipe internal pressure for a piping run (RUN). These pressures are assigned to the elements as they are generated. (See the RUN command description in [Archived Commands](https://ansyshelp.ansys.com/Views/Secured/corp/v232/en/ans_arch/Hlp_C_VALVE.html).)
