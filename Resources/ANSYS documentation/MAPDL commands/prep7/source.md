# SOURCE

PyMAPDL: `mapdl.source(x='', y='', z='', **kwargs)`

Defines a default location for undefined nodes or keypoints.

## Parameters

**x**, **y**, **z**: Global Cartesian coordinates for source nodes or keypoints (defaults to the origin).

## Notes

Defines a global Cartesian location for undefined nodes or keypoints moved during intersection calculations ( [[move|MOVE]] or [[kmove|KMOVE]] ).
