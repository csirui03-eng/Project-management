# EDBVIS

PyMAPDL: `mapdl.edbvis(qvco='', lvco='', **kwargs)`

Specifies global bulk viscosity coefficients for an explicit dynamics

analysis.

## Parameters

**qvco**: Quadratic viscosity coefficient (defaults to 1.5).

**lvco**: Linear viscosity coefficient (defaults to 0.06).

## Notes

This command is also valid in PREP7.

Distributed ANSYS Restriction: This command is not supported in Distributed ANSYS.
