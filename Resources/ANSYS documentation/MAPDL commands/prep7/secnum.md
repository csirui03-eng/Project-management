# SECNUM

PyMAPDL: `mapdl.secnum(secid='', **kwargs)`

Sets the element section attribute pointer.

## Parameters

**secid**: Defines the section ID number to be assigned to the subsequently-defined elements. Defaults to 1. See [[sectype|SECTYPE]] for more information about the section ID number.
