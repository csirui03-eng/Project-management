# FCDELE

PyMAPDL: `mapdl.fcdele(mat='', **kwargs)`

Deletes previously defined failure criterion data for the given material.

## Parameters

**mat**

Material number. Deletes all [[fc|FC]] command input for this material.

A value of ALL deletes all [[fc|FC]] command input for all materials.

## Notes

This command is also valid in POST1.
